Panduan Praktik:
Membuat Game Kuis Interaktif Menggunakan Canvas

Modul praktik terstruktur berorientasi HOTS (Higher Order Thinking Skills). Pelajari arsitektur Unity Canvas, perancangan UI adaptif berbasis Shape, transisi dari skrip per soal ke arsitektur SoalManager, randomisasi soal, hingga sistem countdown timer dan visual feedback interaktif.

# Pendahuluan

Dalam industri game development, kemampuan merancang antarmuka pengguna (**User Interface / UI**) dan memanipulasi alur logika data merupakan keahlian fundamental. Game bergenre kuis edukatif, trivia, maupun minigame berbasis pertanyaan di dalam game RPG membutuhkan sistem UI yang responsif, terstruktur, dan dinamis.

Di modul kedua ini, kita akan membangun sebuah game kuis interaktif di Unity Engine dengan alur belajar bertahap (*scaffolded learning*):

  • Membangun UI Responsif: Memanfaatkan sistem Canvas, RectTransform, dan bentuk dasar (UI Shapes / Image) tanpa ketergantungan aset luar.
  • Evolusi Logika Pemrograman: Memahami mengapa pembuatan skrip manual per soal mudah di awal namun tidak efisien, lalu melakukan refactoring ke pola Data-Driven Architecture menggunakan SoalManager.
  • Fitur Tingkat Lanjut: Menambahkan pengacakan urutan soal (Fisher-Yates Shuffle), visual feedback (indikator benar/salah), batasan waktu mundur (Countdown Timer), serta kalkulasi skor akhir.

01. Setup Canvas & Desain UI Menggunakan Shape

Langkah awal adalah mengonfigurasi Canvas agar tampilan UI dapat beradaptasi secara presisi di berbagai ukuran layar monitor dan merancang elemen-elemen visual menggunakan UI Shapes (Panel, Image, dan Button).

  • 1
    Buat Scene Baru & Tambahkan Canvas: Buka Unity, buat Scene 2D baru bernama QuizGame. Di Hierarchy, klik kanan lalu pilih UI > Canvas. Unity akan otomatis membuat objek Canvas dan EventSystem (komponen pengendali klik mouse / input layar sentuh).
  • 2
    Konfigurasi Canvas Scaler: Klik objek Canvas di Hierarchy. Di panel Inspector pada komponen Canvas Scaler:
    • Ganti UI Scale Mode menjadi Scale With Screen Size.
    • Isi Reference Resolution dengan X: 1920 dan Y: 1080 (Full HD).
    • Atur Match menjadi 0.5 (seimbang antara Width dan Height).
  • 3
    Buat Background Panel: Klik kanan objek Canvas > UI > Panel. Beri nama BackgroundPanel. Pada Inspector, pilih warna gelap kebiruan / abu-abu gelap dengan Alpha 255 (solid) agar tampilan modern.
  • 4
    Buat Question Box (Wadah Pertanyaan): Klik kanan Canvas > UI > Image. Beri nama QuestionBox.
    • Atur Anchor ke Top-Center, atur Pos Y = -220, Width = 1200, Height = 220.
    • Di dalam QuestionBox, buat teks: klik kanan QuestionBox > UI > Text - TextMeshPro. Beri nama QuestionText. Atur font size = 36, Alignment = Center & Middle, dan centang Auto Size / Wrapping.
  • 5
    Buat 4 Tombol Pilihan Jawaban (A, B, C, D):
    • Klik kanan Canvas > UI > Button - TextMeshPro. Beri nama BtnJawaban_A.
    • Atur Width = 1100, Height = 80, dan posisikan di bawah QuestionBox (misal Pos Y = -400).
    • Di dalam tombol, edit komponen Text (TMP) untuk menulis teks opsi jawaban.
    • Duplikasi tombol tersebut (Ctrl + D) sebanyak 3 kali dan beri nama BtnJawaban_B (Pos Y = -500), BtnJawaban_C (Pos Y = -600), dan BtnJawaban_D (Pos Y = -700).
  • 6
    Buat Header Informasi (Nomor Soal & Skor):
    • Buat TextMeshPro baru di bagian atas bernama TextNomorSoal (Pos Y = -60, isi contoh: "Soal 1 / 5").
    • Buat TextMeshPro baru di pojok kanan atas bernama TextSkor (isi contoh: "Skor: 0").

💡 Tips Desain UI Shape

Anda dapat menggunakan sprite kotak bawaan Unity (UISprite atau Square) pada komponen Image tombol, lalu mengganti Source Image dengan sprite bentuk rounded/lingkaran untuk menghasilkan tombol dengan sudut melengkung yang elegan.

02. Tahap 1: Soal Sederhana (Skrip Manual)

Sebagai langkah pengenalan mekanik tombol dan interaksi event, kita akan membuat satu skrip sederhana per soal. Skrip ini secara langsung memeriksa tombol mana yang merupakan jawaban benar.

  • 1
    Buat Script SoalManual: Di folder Assets/Scripts, buat C# script baru bernama SoalManual.
  • 2
    Implementasikan Kode Pemeriksaan Jawaban: Salin kode di bawah ini ke dalam script SoalManual.cs:
SoalManual.cs (Logika Soal Tunggal) 
using UnityEngine;
using TMPro;
using UnityEngine.UI;

public class SoalManual : MonoBehaviour
{
    [Header("Kunci Jawaban")]
    // 0 = A, 1 = B, 2 = C, 3 = D
    public int indexJawabanBenar = 1; 

    [Header("UI Feedback")]
    public TextMeshProUGUI textStatus; // Menampilkan "Benar!" atau "Salah!"

    // Fungsi ini dipanggil saat pemain mengklik tombol opsi jawaban
    public void PilihJawaban(int indexTombol)
    {
        if (indexTombol == indexJawabanBenar)
        {
            textStatus.text = "Jawaban BENAR! (+100 Poin)";
            textStatus.color = Color.green;
            Debug.Log("Jawaban Benar!");
        }
        else
        {
            textStatus.text = "Jawaban SALAH! Coba lagi.";
            textStatus.color = Color.red;
            Debug.Log("Jawaban Salah!");
        }
    }
}
  • 3
    Hubungkan OnClick() pada Tombol di Inspector:
    • Pasang script SoalManual ke objek Canvas atau Empty GameObject.
    • Klik tombol BtnJawaban_A, lihat bagian On Click () di Inspector, klik tombol +.
    • Drag objek ber-script SoalManual ke slot objek OnClick, pilih fungsi SoalManual > PilihJawaban (int) dan isi angka 0.
    • Lakukan hal yang sama untuk Tombol B (isi angka 1), Tombol C (isi angka 2), dan Tombol D (isi angka 3).

⚠️ Evaluasi Keterbatasan Tahap 1

Pendekatan manual ini mengharuskan kita membuat scene/objek terpisah untuk setiap butir soal. Jika ada 50 soal, kita harus membuat 50 halaman UI dan menghubungkan 200 tombol satu per satu. Ini sangat tidak efisien! Oleh karena itu, kita perlu beralih ke SoalManager terpusat pada langkah berikutnya.

03. Tahap 2: Sistem SoalManager Terpusat (Data-Driven)

Pada tahap ini, kita memisahkan Data Soal dari Tampilan UI. Kita hanya membutuhkan 1 template UI yang teksnya akan diganti secara otomatis dari daftar data soal di dalam script QuizManager.

  • 1
    Buat Struktur Data Soal & Script QuizManager: Buat script baru bernama QuizManager di folder Scripts, lalu tuliskan kode terstruktur berikut:
QuizManager.cs (Sistem Data Soal Dinamis) 
using System.Collections;
using System.Collections.Generic;
using UnityEngine;
using UnityEngine.UI;
using TMPro;

// Struktur data untuk menyimpan informasi satu butir soal
[System.Serializable]
public class SoalData
{
    [TextArea(2, 4)]
    public string teksPertanyaan;
    public string[] pilihanJawaban = new string[4]; // 4 pilihan opsi (A, B, C, D)
    public int indexJawabanBenar;                    // 0: A, 1: B, 2: C, 3: D
}

public class QuizManager : MonoBehaviour
{
    [Header("Daftar Soal Kuis")]
    public List<SoalData> daftarSoal = new List<SoalData>();

    [Header("Komponen UI Soal")]
    public TextMeshProUGUI textPertanyaan;
    public TextMeshProUGUI textNomorSoal;
    public TextMeshProUGUI textSkor;
    public Button[] tombolJawaban;                 // Array 4 tombol jawaban

    [Header("Status Permainan")]
    private int indexSoalAktif = 0;
    private int totalSkor = 0;
    private int poinPerSoal = 20;

    void Start()
    {
        TampilkanSoal();
    }

    public void TampilkanSoal()
    {
        if (indexSoalAktif < daftarSoal.Count)
        {
            SoalData soalSekarang = daftarSoal[indexSoalAktif];

            // Update teks nomor dan teks pertanyaan
            textNomorSoal.text = $"Soal {indexSoalAktif + 1} / {daftarSoal.Count}";
            textPertanyaan.text = soalSekarang.teksPertanyaan;
            textSkor.text = $"Skor: {totalSkor}";

            // Update teks pada ke-4 tombol jawaban
            for (int i = 0; i < tombolJawaban.Length; i++)
            {
                TextMeshProUGUI txtBtn = tombolJawaban[i].GetComponentInChildren<TextMeshProUGUI>();
                if (txtBtn != null)
                {
                    txtBtn.text = soalSekarang.pilihanJawaban[i];
                }
            }
        }
        else
        {
            Debug.Log("Semua soal telah selesai dijawab!");
        }
    }

    public void PilihJawaban(int indexDipilih)
    {
        if (indexDipilih == daftarSoal[indexSoalAktif].indexJawabanBenar)
        {
            totalSkor += poinPerSoal;
            Debug.Log("Jawaban Benar!");
        }
        else
        {
            Debug.Log("Jawaban Salah!");
        }

        // Pindah ke soal berikutnya
        indexSoalAktif++;
        TampilkanSoal();
    }
}
  • 2
    Isi Bank Soal di Panel Inspector: Klik objek yang dipasangi script QuizManager. Di Inspector bagian Daftar Soal, masukkan ukuran list (misal: 5). Anda dapat mengetikkan pertanyaan, mengisi 4 opsi jawaban, dan menentukan angka Index Jawaban Benar (0=A, 1=B, 2=C, 3=D) secara fleksibel langsung dari Unity Editor!

04. Tahap 3: Interaksi Jawaban & Visual Feedback

Agar pengalaman bermain lebih memuaskan, tombol yang dipilih pemain harus berubah warna (Hijau untuk jawaban benar, Merah untuk jawaban salah) selama 1 detik sebelum berpindah ke soal berikutnya.

  • 1
    Modifikasi Pemrosesan Jawaban dengan Coroutine: Buka script QuizManager.cs dan perbarui fungsi PilihJawaban menjadi alur IEnumerator:
QuizManager.cs (Penambahan Efek Warna & Delay) 
    [Header("Warna Feedback")]
    public Color warnaNormal = new Color(0.1f, 0.15f, 0.25f, 1f);
    public Color warnaBenar = new Color(0.15f, 0.8f, 0.3f, 1f);
    public Color warnaSalah = new Color(0.9f, 0.2f, 0.2f, 1f);

    private bool sedangMenjawab = false;

    public void PilihJawaban(int indexDipilih)
    {
        if (sedangMenjawab) return; // Cegah spam klik
        StartCoroutine(ProsesJawabanRoutine(indexDipilih));
    }

    private IEnumerator ProsesJawabanRoutine(int indexDipilih)
    {
        sedangMenjawab = true;
        int indexBenar = daftarSoal[indexSoalAktif].indexJawabanBenar;

        if (indexDipilih == indexBenar)
        {
            totalSkor += poinPerSoal;
            tombolJawaban[indexDipilih].GetComponent<Image>().color = warnaBenar;
        }
        else
        {
            tombolJawaban[indexDipilih].GetComponent<Image>().color = warnaSalah;
            // Highlight juga tombol yang seharusnya benar agar edukatif
            tombolJawaban[indexBenar].GetComponent<Image>().color = warnaBenar;
        }

        // Tunggu jeda waktu 1 detik agar pemain melihat hasil jawabannya
        yield return new WaitForSeconds(1.0f);

        // Kembalikan semua tombol ke warna normal
        for (int i = 0; i < tombolJawaban.Length; i++)
        {
            tombolJawaban[i].GetComponent<Image>().color = warnaNormal;
        }

        sedangMenjawab = false;
        indexSoalAktif++;
        TampilkanSoal();
    }

05. Tahap 4: Sistem Randomize (Pengacakan Soal)

Jika urutan soal selalu sama, pemain akan mudah menghafal pola. Kita menerapkan algoritma Fisher-Yates Shuffle untuk mengacak urutan soal secara adil sebelum kuis dimulai.

  • 1
    Implementasi Algoritma Pengacakan: Tambahkan fungsi AcakDaftarSoal() di dalam QuizManager.cs dan panggil fungsi ini di dalam method Start() sebelum soal pertama ditampilkan.
Fisher-Yates Shuffle Algorithm di C# 
    void Start()
    {
        AcakDaftarSoal();
        TampilkanSoal();
    }

    // Algoritma Fisher-Yates untuk mengacak elemen List secara seragam (O(N))
    void AcakDaftarSoal()
    {
        for (int i = daftarSoal.Count - 1; i > 0; i--)
        {
            int randomIndex = Random.Range(0, i + 1);
            
            // Tukar posisi elemen i dengan randomIndex
            SoalData temp = daftarSoal[i];
            daftarSoal[i] = daftarSoal[randomIndex];
            daftarSoal[randomIndex] = temp;
        }
    }

06. Tahap 5: Countdown Timer (Sistem Batas Waktu)

Menambahkan batasan waktu per soal meningkatkan ketegangan dan dinamika bermain. Kita akan membuat visualisasi timer berupa bar progresif (*Filled Image*) dan teks hitung mundur.

  • 1
    Buat UI Timer Bar di Canvas:
    • Klik kanan Canvas > UI > Image, beri nama TimerBarBackground (warna abu-abu gelap).
    • Di dalamnya buat Image anak bernama TimerBarFill (warna Cyan terang).
    • Pada TimerBarFill, ganti Image Type menjadi Filled, Fill Method = Horizontal, Fill Origin = Left.
    • Buat TextMeshPro di samping bar bernama TextTimer untuk menampilkan angka detik (misal: "10s").
  • 2
    Integrasikan Logika Timer ke QuizManager: Tambahkan variabel timer dan kontrol waktu di Update():
Logika Countdown Timer di QuizManager.cs 
    [Header("Pengaturan Timer")]
    public float durasiPerSoal = 15f;
    private float sisaWaktu;
    private bool timerAktif = false;

    public Image imageTimerBar;
    public TextMeshProUGUI textTimer;

    void Update()
    {
        if (timerAktif && !sedangMenjawab)
        {
            sisaWaktu -= Time.deltaTime;

            // Update UI bar & teks
            imageTimerBar.fillAmount = sisaWaktu / durasiPerSoal;
            textTimer.text = $"{(int)Mathf.Ceil(sisaWaktu)}s";

            // Ubah warna bar menjadi merah jika sisa waktu tinggal sedikit (< 4 detik)
            if (sisaWaktu <= 4f)
                imageTimerBar.color = Color.red;
            else
                imageTimerBar.color = new Color(0f, 0.95f, 1f, 1f);

            // Penanganan saat waktu habis
            if (sisaWaktu <= 0)
            {
                timerAktif = false;
                Debug.Log("Waktu Habis!");
                StartCoroutine(WaktuHabisRoutine());
            }
        }
    }

    public void ResetTimer()
    {
        sisaWaktu = durasiPerSoal;
        timerAktif = true;
    }

    private IEnumerator WaktuHabisRoutine()
    {
        sedangMenjawab = true;
        int indexBenar = daftarSoal[indexSoalAktif].indexJawabanBenar;
        tombolJawaban[indexBenar].GetComponent<Image>().color = warnaBenar;

        yield return new WaitForSeconds(1.2f);

        tombolJawaban[indexBenar].GetComponent<Image>().color = warnaNormal;
        sedangMenjawab = false;
        indexSoalAktif++;
        TampilkanSoal();
    }

07. Tahap 6: Layar Hasil (Result Screen)

Saat seluruh pertanyaan selesai dijawab, sistem akan menyembunyikan panel kuis dan memunculkan Result Panel yang menampilkan rangkuman skor, persentase nilai, dan tombol navigasi.

  • 1
    Desain Panel Hasil di Hierarchy: Buat UI Panel bernama ResultPanel di dalam Canvas. Berikan judul "Kuis Selesai!", teks skor akhir, teks predikat kelulusan, tombol "Main Lagi" (Restart), dan tombol "Kembali ke Menu". Nonaktifkan panel ini secara default.
  • 2
    Script Lengkap Terpadu: Berikut adalah kode utuh QuizManager.cs yang menggabungkan seluruh fitur dari Tahap 1 sampai Tahap 6:
QuizManager.cs (Kode Final Lengkap) 
using System.Collections;
using System.Collections.Generic;
using UnityEngine;
using UnityEngine.UI;
using UnityEngine.SceneManagement;
using TMPro;

[System.Serializable]
public class SoalData
{
    [TextArea(2, 4)]
    public string teksPertanyaan;
    public string[] pilihanJawaban = new string[4];
    public int indexJawabanBenar;
}

public class QuizManager : MonoBehaviour
{
    [Header("Bank Soal")]
    public List<SoalData> daftarSoal = new List<SoalData>();

    [Header("Panel UI")]
    public GameObject quizPanel;
    public GameObject resultPanel;

    [Header("Elemen UI Kuis")]
    public TextMeshProUGUI textPertanyaan;
    public TextMeshProUGUI textNomorSoal;
    public TextMeshProUGUI textSkor;
    public Button[] tombolJawaban;

    [Header("Elemen UI Timer")]
    public float durasiPerSoal = 15f;
    public Image imageTimerBar;
    public TextMeshProUGUI textTimer;

    [Header("Elemen UI Result")]
    public TextMeshProUGUI textSkorAkhir;
    public TextMeshProUGUI textFeedback;

    [Header("Warna Tombol Feedback")]
    public Color warnaNormal = new Color(0.1f, 0.15f, 0.25f, 1f);
    public Color warnaBenar = new Color(0.15f, 0.8f, 0.3f, 1f);
    public Color warnaSalah = new Color(0.9f, 0.2f, 0.2f, 1f);

    private int indexSoalAktif = 0;
    private int totalSkor = 0;
    private int jumlahJawabanBenar = 0;
    private int poinPerSoal = 20;
    private float sisaWaktu;
    private bool timerAktif = false;
    private bool sedangMenjawab = false;

    void Start()
    {
        quizPanel.SetActive(true);
        resultPanel.SetActive(false);

        AcakDaftarSoal();
        TampilkanSoal();
    }

    void Update()
    {
        if (timerAktif && !sedangMenjawab)
        {
            sisaWaktu -= Time.deltaTime;
            imageTimerBar.fillAmount = sisaWaktu / durasiPerSoal;
            textTimer.text = $"{(int)Mathf.Ceil(sisaWaktu)}s";

            imageTimerBar.color = (sisaWaktu <= 4f) ? Color.red : new Color(0f, 0.95f, 1f, 1f);

            if (sisaWaktu <= 0)
            {
                timerAktif = false;
                StartCoroutine(WaktuHabisRoutine());
            }
        }
    }

    void AcakDaftarSoal()
    {
        for (int i = daftarSoal.Count - 1; i > 0; i--)
        {
            int randomIndex = Random.Range(0, i + 1);
            SoalData temp = daftarSoal[i];
            daftarSoal[i] = daftarSoal[randomIndex];
            daftarSoal[randomIndex] = temp;
        }
    }

    public void TampilkanSoal()
    {
        if (indexSoalAktif < daftarSoal.Count)
        {
            SoalData soal = daftarSoal[indexSoalAktif];
            textNomorSoal.text = $"Soal {indexSoalAktif + 1} / {daftarSoal.Count}";
            textPertanyaan.text = soal.teksPertanyaan;
            textSkor.text = $"Skor: {totalSkor}";

            for (int i = 0; i < tombolJawaban.Length; i++)
            {
                tombolJawaban[i].GetComponent<Image>().color = warnaNormal;
                tombolJawaban[i].GetComponentInChildren<TextMeshProUGUI>().text = soal.pilihanJawaban[i];
            }

            sisaWaktu = durasiPerSoal;
            timerAktif = true;
        }
        else
        {
            SelesaiKuis();
        }
    }

    public void PilihJawaban(int indexDipilih)
    {
        if (sedangMenjawab) return;
        StartCoroutine(ProsesJawabanRoutine(indexDipilih));
    }

    private IEnumerator ProsesJawabanRoutine(int indexDipilih)
    {
        sedangMenjawab = true;
        timerAktif = false;

        int indexBenar = daftarSoal[indexSoalAktif].indexJawabanBenar;

        if (indexDipilih == indexBenar)
        {
            totalSkor += poinPerSoal;
            jumlahJawabanBenar++;
            tombolJawaban[indexDipilih].GetComponent<Image>().color = warnaBenar;
        }
        else
        {
            tombolJawaban[indexDipilih].GetComponent<Image>().color = warnaSalah;
            tombolJawaban[indexBenar].GetComponent<Image>().color = warnaBenar;
        }

        yield return new WaitForSeconds(1.0f);

        sedangMenjawab = false;
        indexSoalAktif++;
        TampilkanSoal();
    }

    private IEnumerator WaktuHabisRoutine()
    {
        sedangMenjawab = true;
        int indexBenar = daftarSoal[indexSoalAktif].indexJawabanBenar;
        tombolJawaban[indexBenar].GetComponent<Image>().color = warnaBenar;

        yield return new WaitForSeconds(1.2f);

        sedangMenjawab = false;
        indexSoalAktif++;
        TampilkanSoal();
    }

    void SelesaiKuis()
    {
        timerAktif = false;
        quizPanel.SetActive(false);
        resultPanel.SetActive(true);

        textSkorAkhir.text = $"Skor Akhir: {totalSkor}\n(Benar: {jumlahJawabanBenar} dari {daftarSoal.Count} Soal)";

        float persentase = ((float)jumlahJawabanBenar / daftarSoal.Count) * 100f;
        if (persentase >= 80f)
            textFeedback.text = "LUAR BIASA! Penguasaan materi Anda sangat baik!";
        else if (persentase >= 60f)
            textFeedback.text = "BAGUS! Anda lulus, tingkatkan lagi latihan!";
        else
            textFeedback.text = "BELAJAR LAGI! Silakan ulangi modul materi untuk hasil maksimal.";
    }

    public void UlangiKuis()
    {
        SceneManager.LoadScene(SceneManager.GetActiveScene().buildIndex);
    }

    public void KembaliKeMenu()
    {
        SceneManager.LoadScene("MainMenu");
    }
}

# Tantangan Praktik Mandiri (HOTS)

Setelah berhasil mengimplementasikan logika kuis di atas, tingkatkan kemampuan logika pemrograman Anda dengan menyelesaikan tantangan fitur berikut:

⭐ TANTANGAN 1: Sistem Nyawa / Lives (3 Kesempatan)

Tambahkan sistem 3 Nyawa (Heart UI). Jika pemain menjawab salah atau kehabisan waktu, nyawa berkurang 1. Jika nyawa mencapai 0, kuis langsung berakhir (*Game Over*) tanpa harus menyelesaikan seluruh soal. Clue: Tambahkan variabel integer nyawa = 3 dan array Image ikon hati.

⭐ TANTANGAN 2: Pengacakan Opsi Pilihan Jawaban (Answer Shuffling)

Selain mengacak urutan soal, acak juga urutan 4 opsi jawaban (A, B, C, D) di setiap soal tanpa merusak indeks jawaban benar aslinya. Clue: Lacak teks string jawaban yang benar, acak array pilihan, lalu cari kembali indeks baru dari string jawaban yang benar tersebut.

⭐ TANTANGAN 3: Penyimpanan High Score dengan PlayerPrefs

Simpan rekor nilai tertinggi yang pernah diraih pemain ke dalam memori lokal menggunakan PlayerPrefs.SetInt("HighScore", totalSkor) dan tampilkan nilai "Rekor Tertinggi" tersebut di Result Panel dan Main Menu.

# Tugas Proyek Akhir: Mini Game Kuis Edukasi Tematik

Rancang dan bangun sebuah game kuis interaktif yang utuh dan siap dipublikasikan dengan memenuhi 5 ketentuan standar kualitas berikut:

📋 KETENTUAN 1: Tema & Konten Kuis Orisinal

Tentukan 1 tema kuis edukatif (misal: "Pengetahuan Pemrograman C#", "Sejarah Game", "Jaringan Komputer", atau "Logika Algoritma") dan susun minimal 10 butir soal berkualitas tinggi dengan 4 pilihan jawaban yang menantang.

📋 KETENTUAN 2: Desain UI Responsif & Konsisten

Gunakan tata letak Canvas yang rapi dengan Canvas Scaler 1920x1080. Pastikan typography TextMeshPro terbaca jelas, ukuran tombol proporsional untuk diklik, dan warna tema visual menyatu (tidak ada teks terpotong).

📋 KETENTUAN 3: Sistem Randomize & Timer Aktif

Game wajib mengacak urutan soal setiap kali dimainkan dan memiliki Countdown Timer visual per soal dengan penanganan otomatis jika waktu habis.

📋 KETENTUAN 4: Audio & Visual Feedback

Tambahkan efek suara (Sound Effects / SFX) ketika pemain mengklik tombol, saat jawaban benar (*ding*), saat jawaban salah (*buzz*), dan latar musik (BGM). Tombol wajib memberikan feedback perubahan warna sesaat sebelum pindah soal.

📋 KETENTUAN 5: Struktur Scene Lengkap (Menu, Gameplay, Result)

Game memiliki minimal 2 scene yang terhubung: Scene MainMenu (Judul, tombol Mulai, instruksi bermain) dan Scene Gameplay (Layar Kuis dan Layar Hasil Akhir yang memiliki tombol Restart & Kembali ke Menu Utama).

Kumpulan definisi istilah teknis, komponen Unity UI, dan fungsi C# yang digunakan dalam pembuatan game kuis ini:

🎮 Istilah Unity UI

Istilah Penjelasan
Canvas Area akar (*root*) di mana semua komponen UI diletakkan dan dirender di atas layar game.
Canvas Scaler Komponen pengendali skala antarmuka agar posisi dan ukuran elemen UI otomatis menyesuaikan aspek rasio layar pemain.
RectTransform Komponen pengganti Transform biasa khusus objek UI untuk mengatur posisi, ukuran, anchor, dan pivot dalam bidang 2D.
EventSystem Komponen pengelola input interaktif yang mendeteksi klik kursor, hover, sentuhan layar, dan navigasi tombol keyboard/gamepad pada UI.
TextMeshProUGUI Komponen perender teks berbasis Signed Distance Field (SDF) yang menghasilkan tipografi sangat tajam di berbagai resolusi.
Image (Filled) Mode gambar UI yang persentase tampilannya dapat dikontrol dari nilai 0.0 sampai 1.0 (sangat berguna untuk HP bar, timer bar, dan progress bar).

⚙️ Fungsi & Konsep C#

Fungsi / Keyword Penjelasan
[System.Serializable] Atribut C# agar sebuah class custom dapat dimunculkan, diisi, dan diedit secara visual di panel Inspector Unity.
IEnumerator / Coroutine Fungsi khusus di Unity yang dapat menunda eksekusi kode selama durasi waktu tertentu menggunakan yield return new WaitForSeconds(detik) tanpa membekukan game.
Fisher-Yates Shuffle Algoritma komputasi untuk mengacak urutan elemen dalam array/list dengan kompleksitas efisien $O(N)$ dan probabilitas yang setara.
Time.deltaTime Waktu selisih antar frame dalam detik. Digunakan untuk mengurangi nilai timer secara halus dan independen dari fluktuasi framerate komputer.
PlayerPrefs Sistem penyimpanan data lokal bawaan Unity untuk menyimpan variabel sederhana (Integer, Float, String) seperti skor tertinggi dan preferensi audio.
