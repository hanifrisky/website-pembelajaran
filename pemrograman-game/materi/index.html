Daftar Modul Pemrograman Gim

Pilih materi di bawah ini untuk menampilkan panduan praktik interaktif dan membuat game berkualitas tinggi.

MATERI 01

Game Platformer 2D

Pelajari pembuatan game platformer di Unity. Pembahasan mendalam mulai dari setup character, pergerakan horizontal, lompatan, deteksi ground check, kamera dinamis, patroli musuh, hingga visualisasi Game Over.

📖 Buka Modul
MATERI 02

Game Kuis Interaktif (Canvas UI) 🔒

Pelajari pembuatan game kuis berbasis Canvas di Unity. Mulai dari layout UI menggunakan Shape, skrip soal bertahap, arsitektur SoalManager, randomisasi soal, hingga sistem countdown timer.

🔒 Belum Tersedia
MATERI 03

Simple Leaderboard (REST API)

Pelajari integrasi REST API di Unity menggunakan UnityWebRequest. Mengambil data peringkat (GET), parsing JSON ke model C#, membuat daftar UI secara dinamis pada Scroll View vertikal, serta mengirimkan skor pemain baru (POST).

📖 Buka Modul
MATERI 04

Inventory & Collectibles 🔒

Membangun sistem inventaris berbasis ScriptableObject, menangani pengambilan item koin/kunci, sistem UI grid dinamis, dan mekanisme item usage.
