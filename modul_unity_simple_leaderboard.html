2. Konsep Dasar API dan REST API

A. Apa itu API (Application Programming Interface)?

Secara sederhana, API (Application Programming Interface) adalah antarmuka atau jembatan penghubung yang memungkinkan dua sistem perangkat lunak yang berbeda untuk saling berkomunikasi, bertukar data, dan bekerja sama tanpa harus mengetahui detail teknis internal masing-masing.

🍽️ Analogi Dunia Nyata: Pelayan di Restoran
Bayangkan Anda sedang makan di sebuah restoran:
  • Tamu (Pelanggan) = Unity Game (Client): Anda ingin memesan makanan tertentu yang tercantum pada menu.
  • Pelayan = API: Mencatat pesanan Anda, membawanya ke dapur, menunggu masakan siap, lalu mengantarkan makanan yang sudah jadi kembali ke meja Anda. Anda tidak perlu tahu cara kerja kompor atau resep rahasia di dapur.
  • Dapur & Gudang = Web Server & Database: Tempat penyimpanan bahan mentah dan pengolahan data yang memasak pesanan sesuai permintaan.

B. Apa itu REST API (RESTful API)?

REST (Representational State Transfer) adalah standar arsitektur komunikasi web yang paling luas digunakan di dunia. REST API bekerja di atas protokol standar internet, yaitu HTTP / HTTPS—protokol yang sama seperti saat kita berselancar di web browser.

Karakteristik penting dalam arsitektur REST API:

  • Client-Server: Game Unity (Client) berfokus pada grafis, input kontroler, dan gameplay, sedangkan Server berfokus pada penyimpanan data terpusat dan validasi keamanan. Keduanya independen.
  • Stateless: Setiap request yang dikirimkan oleh Unity harus mandiri dan membawa semua data yang dibutuhkan. Server tidak menyimpan riwayat percakapan sebelumnya antar-request.
  • Resource-Based: Setiap informasi di server diperlakukan sebagai sebuah sumber daya (resource) yang memiliki alamat unik bernama Endpoint / URL (contoh: /simple-leaderboard).
  • Format Standar (JSON): Pertukaran informasi dilakukan dalam format teks JSON yang terstruktur dan hemat ukuran bandwidth.

C. 4 Metode Utama HTTP (HTTP Verbs / Methods)

Ketika Unity berkomunikasi dengan REST API, Unity menentukan jenis tindakan yang diinginkan menggunakan HTTP Method (identik dengan operasi CRUD di basis data):

GET Mengambil / Membaca Data (Read)

Meminta data dari server tanpa mengubah apapun di database. Contoh: Mengambil 10 daftar skor teratas untuk ditampilkan pada layar game.

POST Mengirim Data Baru (Create)

Mengirim data baru dari game ke server untuk disimpan ke dalam database. Contoh: Mengirim nama pemain dan skor akhir saat Game Over.

PUT / PATCH Memperbarui Data (Update)

Mengubah atau memperbarui data yang sudah ada di server. Contoh: Mengganti nama akun atau memperbarui pengaturan profil pemain.

DELETE Menghapus Data (Delete)

Menghapus data tertentu dari server. Contoh: Mereset skor musim lalu atau menghapus riwayat permainan.

D. Mengenal HTTP Status Code (Kode Respon Server)

Server akan selalu membalas setiap request dengan kode status numerik 3-digit untuk memberitahukan status permintaan:

KodeNama StatusKategoriArti dalam Game
200OK2xx (Sukses)Permintaan berhasil dan server mengembalikan data (misal: sukses GET leaderboard).
201Created2xx (Sukses)Data baru berhasil dibuat dan disimpan di server (misal: sukses POST skor baru).
400Bad Request4xx (Client Error)Format data yang dikirim game salah (misal: nama kosong atau nilai non-angka).
404Not Found4xx (Client Error)Alamat endpoint salah atau resource yang dicari tidak ada di server.
500Internal Server Error5xx (Server Error)Terjadi kesalahan atau crash di sisi server backend.

E. Anatomi Format JSON

JSON (JavaScript Object Notation) adalah format teks ringkas untuk merepresentasikan struktur data. Unity memiliki library bawaan JsonUtility untuk mengubah objek C# menjadi JSON (serialization) dan sebaliknya (deserialization).

  • Object { }: Kumpulan data pasangan "key": value. Contoh: {"nama": "Budi", "nilai": 950}.
  • Array [ ]: Kumpulan daftar item berturut-turut. Contoh: [10, 20, 30] atau daftar data pemain.
  • Tipe data valid: String (teks bertanda kutip), Number (angka), Boolean (true/false), Array, Object, dan null.

F. Mengapa Game Memerlukan REST API?

🌍 Leaderboard Lintas Platform

Pemain di PC, Android, iOS, maupun WebGL dapat bersaing di satu papan peringkat global yang sama secara realtime.

🛡️ Keamanan & Integritas Data

Skor tersimpan di server aman, bukan di penyimpanan lokal perangkat (PlayerPrefs) yang rawan dimodifikasi atau dicurangi pemain.

⚡ Konten Dinamis Tanpa Update

Daftar event khusus, pesan pengumuman, atau hadiah harian dapat diperbarui dari server tanpa pemain harus download update aplikasi baru.

🔄 Komunikasi Asinkron (Anti-Lag)

Melalui UnityWebRequest dan Coroutine (IEnumerator), proses unduh/unggah berjalan di latar belakang sehingga gameplay tidak patah-patah.

3. Pengenalan UnityWebRequest & Latihan Console (GET & POST)

A. Apa itu UnityWebRequest & Mengapa Harus Asinkron?

Di Unity, seluruh komunikasi pertukaran data melalui internet ditangani oleh class UnityWebRequest yang terdapat di dalam namespace UnityEngine.Networking.

⏳ Mengapa Komunikasi Web Harus Menggunakan Coroutine (Asinkron)?
Ketika game meminta data ke server melalui internet, diperlukan waktu sekian milidetik hingga detik (tergantung koneksi). Jika dipanggil secara biasa (sinkron/blocking), seluruh proses rendering Unity akan langsung membeku (freeze / hang) menunggu respon server.

Oleh karena itu, di Unity kita wajib menggunakan Coroutine (IEnumerator) dan kata kunci yield return request.SendWebRequest();. Unity akan mengirim request ke latar belakang (background thread), sementara gameplay tetap berjalan mulus di 60 FPS. Script baru akan melanjutkan eksekusi setelah server selesai merespons!

C. Latihan 1: Mengambil Data Menggunakan HTTP GET (Output di Console)

Pada latihan ini, kita akan membuat script sederhana untuk meminta data ke server dan mencetak isi data mentah (raw JSON) langsung ke tab Console Unity tanpa perlu membuat antarmuka UI terlebih dahulu.

Buat file C# baru di folder Assets/Scripts dengan nama LatihanGetConsole.cs:

using System.Collections;
using UnityEngine;
using UnityEngine.Networking;

public class LatihanGetConsole : MonoBehaviour
{
    // Endpoint API leaderboard (dibatasi 3 data untuk pengujian)
    private string url = "https://simple-api.appocket.id/simple-leaderboard?limit=3";

    void Start()
    {
        Debug.Log("--- Memulai Latihan HTTP GET ---");
        StartCoroutine(GetDataFromServer());
    }

    IEnumerator GetDataFromServer()
    {
        Debug.Log("Mengirim request GET ke: " + url);

        // 1. Buat request GET menggunakan UnityWebRequest
        using (UnityWebRequest request = UnityWebRequest.Get(url))
        {
            // 2. Kirim request secara asinkron dan tunggu hingga server membalas
            yield return request.SendWebRequest();

            // 3. Periksa apakah terjadi error jaringan / protokol
            if (request.result != UnityWebRequest.Result.Success)
            {
                Debug.LogError("[GET ERROR] Gagal mengambil data: " + request.error);
                Debug.LogError("HTTP Status Code: " + request.responseCode);
            }
            else
            {
                // 4. Jika berhasil, tampilkan status code dan isi teks JSON mentah
                Debug.Log("[GET SUKSES] Data berhasil diterima dari server!");
                Debug.Log("HTTP Status Code: " + request.responseCode);

                string jsonHasil = request.downloadHandler.text;
                Debug.Log("Isi Data JSON dari Server:\n" + jsonHasil);
            }
        }
    }
}

Langkah Pengujian Latihan GET di Unity:

  1. Di panel Hierarchy Unity, klik kanan lalu pilih Create Empty. Beri nama objek: Test_GET.
  2. Seret file script LatihanGetConsole.cs ke objek Test_GET di Hierarchy atau melalui tombol Add Component.
  3. Buka panel Console Unity (menu Window → General → Console atau tekan Ctrl + Shift + C).
  4. Tekan tombol Play ▶ di Unity Editor.

D. Latihan 2: Mengirim Skor Baru Menggunakan HTTP POST (Output di Console)

Berbeda dengan GET yang hanya meminta data, pada metode POST kita harus membungkus data baru yang ingin kita kirim ke server (dikenal sebagai Payload / Body).

Alur teknis pengiriman data POST di Unity:

  • Menyusun data dalam format string JSON: {"nama": "Nama Pemain", "nilai": 900}.
  • Mengonversi string JSON menjadi barisan byte: Encoding.UTF8.GetBytes(jsonBody).
  • Memasang UploadHandlerRaw (pengirim data) dan DownloadHandlerBuffer (penerima respon server).
  • Menetapkan header: request.SetRequestHeader("Content-Type", "application/json") agar server mengenali tipe data yang dikirim.

Buat file C# baru di folder Assets/Scripts dengan nama LatihanPostConsole.cs:

using System.Collections;
using System.Text;
using UnityEngine;
using UnityEngine.Networking;

public class LatihanPostConsole : MonoBehaviour
{
    // Endpoint API untuk mengirim skor
    private string url = "https://simple-api.appocket.id/simple-leaderboard";

    [Header("Data Skor Baru yang Dikirim")]
    public string namaPemain = "Siswa SMK Telkom";
    public int skorPemain = 920;

    void Start()
    {
        Debug.Log("--- Memulai Latihan HTTP POST ---");
        StartCoroutine(KirimSkorKeServer(namaPemain, skorPemain));
    }

    IEnumerator KirimSkorKeServer(string nama, int skor)
    {
        Debug.Log("Menyiapkan payload POST untuk: " + nama + " (" + skor + ")");

        // 1. Susun string JSON sesuai format yang diterima server
        string jsonPayload = "{\"nama\":\"" + nama + "\",\"nilai\":" + skor + "}";
        Debug.Log("Payload JSON: " + jsonPayload);

        // 2. Konversi string JSON ke byte array UTF-8
        byte[] bodyRaw = Encoding.UTF8.GetBytes(jsonPayload);

        // 3. Buat UnityWebRequest dengan method POST
        using (UnityWebRequest request = new UnityWebRequest(url, "POST"))
        {
            // Pasang pengirim (UploadHandler) dan penerima (DownloadHandler)
            request.uploadHandler = new UploadHandlerRaw(bodyRaw);
            request.downloadHandler = new DownloadHandlerBuffer();

            // Set Header agar server mengenali format JSON
            request.SetRequestHeader("Content-Type", "application/json");

            // 4. Kirim request ke server dan tunggu respon secara asinkron
            yield return request.SendWebRequest();

            // 5. Periksa status pengiriman
            if (request.result != UnityWebRequest.Result.Success)
            {
                Debug.LogError("[POST ERROR] Gagal mengirim data: " + request.error);
                Debug.LogError("HTTP Status Code: " + request.responseCode);
                Debug.LogError("Pesan Error Server: " + request.downloadHandler.text);
            }
            else
            {
                Debug.Log("[POST SUKSES] Skor berhasil dikirim ke database server!");
                Debug.Log("HTTP Status Code: " + request.responseCode);
                Debug.Log("Balasan dari Server:\n" + request.downloadHandler.text);
            }
        }
    }
}

5. Membuat Model Data JSON

Buat folder Assets/Scripts, lalu buat file LeaderboardModels.cs. Class ini menyesuaikan struktur JSON dengan objek C#.

using System;

[Serializable]
public class LeaderboardEntry
{
    public int rank;
    public int id;
    public string nama;
    public int nilai;
    public string created_at;
}

[Serializable]
public class LeaderboardResponse
{
    public string status;
    public int total;
    public LeaderboardEntry[] data;
}

[Serializable]
public class LeaderboardSubmit
{
    public string nama;
    public int nilai;
}
  • LeaderboardEntry: satu baris data pemain.
  • LeaderboardResponse: respons GET yang berisi status, total, dan array data.
  • LeaderboardSubmit: data nama dan nilai yang akan dikirim ke server.
  • [Serializable]: memungkinkan JsonUtility melakukan serialisasi/deserialisasi objek.
Model di atas mengasumsikan nilai dikirim sebagai angka JSON, seperti pada contoh API. Jika server mengirimnya sebagai string, sesuaikan tipe datanya.

7. Script Utama: GET, POST, dan Refresh

Buat file LeaderboardManager.cs. Script ini mengunduh data, membangun baris UI, mengirim skor, dan mengambil ulang data setelah POST berhasil.

using System.Collections;
using System.Text;
using TMPro;
using UnityEngine;
using UnityEngine.Networking;

public class LeaderboardManager : MonoBehaviour
{
    private const string API_URL =
        "https://simple-api.appocket.id/simple-leaderboard";

    [Header("Leaderboard UI")]
    public Transform content;
    public GameObject leaderboardItemPrefab;
    public int limit = 10;

    [Header("Input UI")]
    public TMP_InputField namaInput;
    public TMP_InputField nilaiInput;

    [Header("Status UI")]
    public TMP_Text statusText;

    private bool isProcessing;

    private void Start()
    {
        StartCoroutine(GetLeaderboard());
    }

    // GET: mengambil data leaderboard
    public IEnumerator GetLeaderboard()
    {
        string url = API_URL + "?limit=" + Mathf.Max(1, limit);

        using (UnityWebRequest request = UnityWebRequest.Get(url))
        {
            request.timeout = 15;
            yield return request.SendWebRequest();

            if (request.result != UnityWebRequest.Result.Success)
            {
                SetStatus("Gagal mengambil data: " + request.error);
                Debug.LogError("GET Error: " + request.error +
                    "\\nResponse: " + request.downloadHandler.text);
                yield break;
            }

            string json = request.downloadHandler.text;
            Debug.Log("GET Response: " + json);

            LeaderboardResponse response;
            try
            {
                response = JsonUtility.FromJson(json);
            }
            catch (System.Exception e)
            {
                SetStatus("Gagal membaca JSON.");
                Debug.LogError(e.Message);
                yield break;
            }

            if (response == null || response.status != "success"
                || response.data == null)
            {
                SetStatus("Format data leaderboard tidak valid.");
                yield break;
            }

            DisplayLeaderboard(response.data);
            SetStatus("Leaderboard berhasil dimuat: " +
                response.total + " data.");
        }
    }

    private void DisplayLeaderboard(LeaderboardEntry[] entries)
    {
        // Hapus baris lama agar tidak terjadi duplikasi.
        foreach (Transform child in content)
        {
            Destroy(child.gameObject);
        }

        foreach (LeaderboardEntry entry in entries)
        {
            GameObject item = Instantiate(leaderboardItemPrefab, content);
            LeaderboardItemUI itemUI = item.GetComponent();

            if (itemUI != null)
            {
                itemUI.SetData(entry);
            }
            else
            {
                Debug.LogError("Prefab tidak memiliki LeaderboardItemUI.");
            }
        }
    }

    // POST: validasi input sebelum mengirim skor
    public void SubmitScore()
    {
        if (isProcessing)
            return;

        string nama = namaInput.text.Trim();
        string nilaiString = nilaiInput.text.Trim();

        if (string.IsNullOrEmpty(nama))
        {
            SetStatus("Nama pemain harus diisi.");
            return;
        }

        if (!int.TryParse(nilaiString, out int nilai) || nilai < 0)
        {
            SetStatus("Nilai harus berupa angka 0 atau lebih.");
            return;
        }

        StartCoroutine(PostLeaderboard(nama, nilai));
    }

    private IEnumerator PostLeaderboard(string nama, int nilai)
    {
        isProcessing = true;
        SetStatus("Mengirim skor...");

        LeaderboardSubmit submitData = new LeaderboardSubmit
        {
            nama = nama,
            nilai = nilai
        };

        string json = JsonUtility.ToJson(submitData);
        byte[] bodyRaw = Encoding.UTF8.GetBytes(json);

        using (UnityWebRequest request = new UnityWebRequest(API_URL, "POST"))
        {
            request.uploadHandler = new UploadHandlerRaw(bodyRaw);
            request.downloadHandler = new DownloadHandlerBuffer();
            request.SetRequestHeader("Content-Type", "application/json");
            request.SetRequestHeader("Accept", "application/json");
            request.timeout = 15;

            yield return request.SendWebRequest();

            string responseBody = request.downloadHandler.text;
            Debug.Log("POST Response: " + responseBody);

            if (request.result != UnityWebRequest.Result.Success)
            {
                SetStatus("Gagal mengirim skor: " + request.error);
                Debug.LogError("POST Error: " + request.error +
                    "\\nResponse: " + responseBody);
                isProcessing = false;
                yield break;
            }

            SetStatus("Skor berhasil dikirim.");
            namaInput.text = "";
            nilaiInput.text = "";

            // Ambil data terbaru dari server.
            yield return GetLeaderboard();
        }

        isProcessing = false;
    }

    public void RefreshLeaderboard()
    {
        if (!isProcessing)
            StartCoroutine(GetLeaderboard());
    }

    private void SetStatus(string message)
    {
        if (statusText != null)
            statusText.text = message;

        Debug.Log(message);
    }
}

Bagaimana script bekerja?

  • GET: UnityWebRequest.Get(url) meminta data, lalu JsonUtility.FromJson mengubah respons menjadi objek C#.
  • Instantiate: membuat satu prefab untuk setiap pemain di dalam Content.
  • POST: JsonUtility.ToJson mengubah input menjadi JSON, kemudian UploadHandlerRaw mengirimkannya ke server.
  • Refresh: setelah POST sukses secara HTTP, coroutine GET dijalankan lagi untuk mengambil daftar terbaru.
Penting: script menganggap respons HTTP sukses berarti server menerima data. Jika API memiliki format respons khusus untuk menolak skor, periksa isi respons itu juga sebelum menampilkan pesan berhasil. Kode ini belum membuktikan bahwa skor telah tersimpan secara permanen.

9. Pengujian Praktik

  1. Jalankan game. Method Start() otomatis meminta data leaderboard.
  2. Pastikan data muncul sebagai baris-baris di Scroll View.
  3. Masukkan nama Rian Ardiansyah dan nilai 920.
  4. Tekan Kirim dan periksa status serta Console.
  5. Jika POST berhasil, daftar dimuat ulang menggunakan GET.
  6. Tekan Refresh untuk mengambil data server lagi secara manual.

Kesimpulan: dengan UnityWebRequest, model data C#, prefab UI, dan Scroll View, leaderboard dapat mengambil dan mengirim data secara dinamis tanpa membuat baris pemain satu per satu.

Catatan keamanan: endpoint pada modul ini menggunakan HTTPS dan tidak memerlukan token menurut spesifikasi yang diberikan. Untuk game produksi, validasi skor di server agar client tidak bisa mengirim skor palsu.
